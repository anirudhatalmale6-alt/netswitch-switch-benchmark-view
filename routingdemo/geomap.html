Placing the IP / POP map onto a real map

Each node is positioned by its true latitude / longitude through an equirectangular map projection — no Google Maps, no HSL, no tiles. Fully self-contained and original.

How an IP lands on a map: IP address → geolocation gives a (latitude, longitude) → a projection converts lat/long to an (x, y) pixel. Here the projection is equirectangular: x scales with longitude, y with latitude. Swap in a real coastline base underneath (OpenStreetMap data we render ourselves — open license, we own the styling) and these exact same node positions sit on top of real geography. The math that places the dot does not change; only the backdrop does.
